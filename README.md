- Мастюгин Михаил
- Иванов Семён
## Входные данные
Граф задаётся в файле circuit.json. При задании графа указывается:
 - имя рёбра
 - тип рёбра
 - из какой вершины ребро выходит
 - в какую вершину ребро приходит
 - значение ребра

В консоли при вводе анализируемых переменных указать искомые величины, из которых будет составлен вектор Y (в нашем примере I_R2 и I_C)
## Выходные данные
 - вектор Y
 - графики изменения X и Y по времени (хранятся в папке Images)
